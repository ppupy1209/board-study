# 모두의 광장

주제를 가리지 않고 글을 쓰며 댓글로 이야기를 이어 가는 커뮤니티입니다. 새 글부터 인기글까지 한곳에서 둘러보고, 마음에 드는 글에는 좋아요를 남길 수 있습니다.

![모두의 광장 홈 화면](docs/images/modu-square-home.png)

## 모두의 광장에서 할 수 있는 일

- 게시판의 새 글을 둘러보다가 다음 페이지를 계속 불러올 수 있습니다.
- 글을 쓰고 고치거나 삭제할 수 있습니다.
- 댓글에 답글을 달며 대화를 이어 갈 수 있습니다.
- 좋아요와 조회수로 글의 반응을 확인할 수 있습니다.
- 여러 게시판에서 반응이 좋은 글을 인기글로 만날 수 있습니다.
- 이미지를 첨부하면 업로드가 끝난 뒤 게시글에 바로 표시됩니다.

![이미지가 첨부된 게시글](docs/images/media-cost/article-image.png)

## 로컬 실행

```bash
docker compose up --build
```

실행이 끝나면 `http://localhost:3000`에서 모두의 광장을 열 수 있습니다. 처음에는 자유게시판에 데모 글 100건이 준비됩니다. 데이터를 따로 만들지 않아도 화면과 기능을 바로 확인할 수 있습니다.

기본 웹 포트를 다른 프로그램이 사용 중이라면 저장소 루트에 `.env` 파일을 만들고 포트를 바꿉니다.

```env
WEB_PORT=3002
```

서비스를 종료할 때는 다음 명령을 사용합니다.

```bash
docker compose down
```

작성한 글과 첨부 이미지를 포함한 로컬 데이터는 Docker 볼륨에 남습니다. 데이터를 함께 지우려는 경우에만 `docker compose down -v`를 사용합니다.
